    [:octicons-arrow-right-24: Redes](redes.md)

-   :material-penguin:{ .lg .middle } **Linux**

    ---

    La terminal, permisos, usuarios y servicios. El SO del hacker.

    [:octicons-arrow-right-24: Linux](linux.md)

-   :material-microsoft-windows:{ .lg .middle } **Windows**

    ---

    Usuarios, Active Directory, logs y la consola. El SO que vas a defender/auditar más.

</div>
